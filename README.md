# 自動化工程師 刷題網站

純靜態網頁（HTML + JS），不需要後端，放在 GitHub Pages 即可。支援多個科目（目前：自動化概論 600 題、電工概論 585 題）。

## 功能
- 多科目切換（右上角選單或首頁「所有科目」），每科的紀錄各自獨立
- 自選題號範圍與題數；隨機 / 依題號；每次重新打亂選項（「以上皆是」、數字大小排列、圖形選項固定順序）
- 每題立即看答案，或交卷後再看；正計時
- 錯題本、收藏、只刷沒做過的題、交卷後一鍵重刷錯題
- 題號地圖（一眼看出哪些做過、對錯），點一格從該題開始刷
- **中途離開也不怕**：未完成的測驗會存起來，回首頁按「繼續作答」
- 可安裝成手機 App（PWA）、**離線可用**；手機可左右滑動換題
- 作答紀錄存在瀏覽器 localStorage，支援匯出／匯入備份（所有科目一起）

## 在本機開啟
直接雙擊 `index.html` 即可（離線快取與安裝功能需要 http(s)，本機雙擊時不會啟用）。

## 補題目 / 新增科目
```
source/
  automation/            ← 科目代號
    subject.json         ← 科目名稱、圖示、排序
    q001.txt … q012.txt  ← 題目，依檔名排序後累計題號
  electrical/            ← 電工概論（行首帶題號的格式，可跳號）
    subject.json
    q001.txt             ← 之後把電工概論題目放這裡
images/<科目代號>/q064.jpg   ← （選用）第 64 題的原書附圖
```
每行一題，用 `|` 分隔：
```
題目|選項A|選項B|選項C|選項D|答案(A~D)|旗標(可省略)|備註(可省略)
```
- 旗標 `F`：固定選項順序；`FIG`：選項是原書的圖
- 選項含「以上皆是/皆非」會自動固定順序
- 備註會在作答後顯示（例如「這題答案待核對」）
- 有放 `images/<科目>/qNNN.jpg` 的題目，會自動顯示圖片，並隱藏文字版的【圖：…】描述

補完後執行：
```
python scripts/build_data.py
git add . && git commit -m "add questions" && git push
```
新增的題目接在最後面，舊題號與學習紀錄不受影響。
新增整個科目：建立 `source/<代號>/subject.json` 與題目檔，執行 build，科目就會出現在選單。
